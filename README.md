# Firebase Authentication – Android App (Jetpack Compose)  

Este projeto consiste em desenvolver um **aplicativo mobile de autenticação** utilizando **Firebase Authentication** e **Jetpack Compose**.  
O foco está em criar uma **interface moderna e responsiva**, com **boas práticas de UI/UX**, integração com o **Firebase**, e navegação fluida entre telas de login, cadastro e tela inicial.  

## 📱 Features  

- **Autenticação de Usuários**  
  - Registro de novos usuários com **e-mail e senha**.  
  - Login de usuários existentes com **Firebase Authentication**.  
  - Redirecionamento automático para a **tela inicial** após autenticação.  
  - Opção de **logout** para encerrar a sessão do usuário.  

- **Integração com Firebase**  
  - Utiliza o **Firebase Authentication** para autenticação segura.  
  - Gerenciamento completo de contas de usuário pelo Firebase.  
  - Tratamento de erros (e-mail já cadastrado, credenciais inválidas, etc.).  

- **UI/UX – Jetpack Compose + Material 3**  
  - Interface desenvolvida inteiramente com **Jetpack Compose**.  
  - **Layout moderno** com **gradiente**, **cartões**, **animações leves** e **estilo Material 3**.  
  - Campo de senha com opção de **exibir/ocultar senha**.  
  - Uso de **Snackbars** para feedbacks elegantes em vez de Toasts.  
  - **Tela inicial personalizada**, com avatar dinâmico e design coerente com o tema.
